### Приложение загружает файлы с изображениями собак указанной вами породы (включая все под-породы, если таковые имеются) из https://dog.ceo/dog-api в вашу папку на Яндекс Диске (https://360.yandex.ru/disk/), а также генерирует и изменяет JSON файл с названиями и размерами загруженых файлов.

#### Приложению необходим OAuth token из https://yandex.ru/dev/disk/poligon/

#### Этот токен должен быть помещён в переменную "token" в модуле "settings.py" (как показано в модуле "settings.example.py".

#### Папка для этих файлов с изображениями собак на вашем Яндекс Диске также создаётся этим приложением. Имя папки - указанная вами порода собаки.

#### Команда "YD = YandexDisk()" создаёт объект "YD" класса "YandexDisk", который позволяет вам использовать его методы.

#### Метод "YD.enter_dog_breed()" осуществляет цикл, который который предлагает ввести название породы или цифру 0 (чтобы выйти из цикла), запрашивает информацию о введённой вами породе на сайте https://dog.ceo/dog-api и вызывает метод "get_dog_url(self, folder_name, partial)".

#### Метод "get_dog_url(self, folder_name, partial)" загружает картинки собак с сайта https://dog.ceo/dog-api и вызывает следующие методы:

#### 1) метод "create_folder(self, folder_name, partial_share)" создаёт папку с названием породы собаки на вашем Яндекс Диске.

#### 2) метод "upload_file_to_folder(folder_name, name_file, file_extension, content, last_share)" загружает файл(ы) с изображением собаки в вышеупомянутую папку на вашем Яндекс Диске.

#### 3) статический метод "get_dog_file_info(file_name, file_extension, image_size)" отвечает за создание и изменение JSON файла с названиями и размерами файлов, загруженных в вышеупомянутую папку на вашем Яндекс Диске. Все параметры этого статического метода относятся к типу "String". Название JSON файла - "image_size_data.json"

#### Приложение информирует вас об успешном (или нет) выполнении всех важных этапов, а также иллюстрирует продвижение выполнения приложения посредством численно-графической шкалы от 0 до 100%.
